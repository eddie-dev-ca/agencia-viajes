# Wanderly | Travel Agency

Página de una agencia de viajes ficticia, hecha en **HTML puro**. Proyecto de práctica mientras aprendo desarrollo web.

**Ver la página:** https://eddie-dev-ca.github.io/agencia-viajes/

## Qué practiqué

| Concepto | Dónde se ve |
|---|---|
| Estructura del documento | `DOCTYPE`, `html lang="en"`, `head`, `body` |
| Jerarquía de encabezados | Un solo `h1` y varios `h2` |
| Listas desordenadas | Paquetes y datos de contacto |
| `figure` y `figcaption` | Las tres imágenes de destinos |
| Imagen dentro de un enlace | `a` > `img` dentro de cada `figure` |
| Atributo `alt` | Cada imagen |
| `id` y enlaces internos | `#itineraries` y `#contact` |
| Elemento `section` | Sección de contacto |

## Lo que no se ve: etiquetas `meta`

- `meta name="description"`: resumen de la página para los buscadores.
- Open Graph: controla cómo se ve el enlace al compartirlo en redes sociales.
  - `og:title`: título de la tarjeta.
  - `og:type`: tipo de contenido (`website`).
  - `og:image`: imagen de vista previa.
  - `og:url`: dirección oficial de la página.
